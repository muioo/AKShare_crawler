# AKShare 股票数据爬取工具

## 简介
基于AKShare库开发的股票数据GUI工具，支持实时行情、资金流向、单股分析、同行比较等功能。

## 使用方法
```bash
pip install requirements.txt
pyhton run_gui.py
```
pip install requirements.txt
run_gui.py

## 功能特点
- 实时股票行情（沪深京A股、B股、AH股、科创版）
- 单股历史走势分析
- 同行财务指标对比
- 自动定时更新（30分钟）
- 数据自动清理（保留3天）

## 注意事项
- 需要稳定的网络连接
- 首次运行较慢
- 建议定期清理数据
